# paper/

* `Encoding_Imagism.pdf`: Bizzoni, Feldkamp & Nielbo (2026), "Encoding Imagism?", *Journal of Computational Literary Studies* 5(1).
* `pages/p-NN.jpg`: one image per page, used by the report viewer for previews.
* `words.json`: the position of every word on every page, used to highlight quoted passages.

The images and `words.json` are made by `make_words_json.py` (needs poppler-utils). Rerun it if the PDF changes.
